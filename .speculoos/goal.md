# Goal

Make `millefeuille` the trustworthy, restartable CLI control surface for the
complete research-paper lifecycle: bounded source discovery, verified recovery,
durable source packs, extraction and reconstruction, provenance-backed
knowledge products, retrieval/index reconciliation, evidence-first
classification, and governed writeback.

The stage manifest and artifact index are the durable state authorities.
Source identity, provider/model choice, index identity, classification lineage,
and every approved side effect must remain auditable without committing
credentials, authenticated URLs, raw PDF bytes, provider payloads, prompts, or
private paper content.

The current implementation program starts from the merged offline contract on
`dev`, first restores a truthful cross-platform release baseline, then adds
approved-live stages behind scoped receipts and bounded dogfood gates. Stable
promotion, tags, package publication, and live external writes remain explicit
gates even while repository-local implementation proceeds autonomously.
