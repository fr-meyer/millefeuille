# Ordinary native source boundary

This publication supports the ordinary explicit native SDK route: one-paper
intake, ordinary files/result OCR evidence, canonical or authenticated v1 physical
response readback, clean final proof/completion and independently reviewed
one-entry scientific-note preparation/publication. Existing legacy three-entry
standalone approval and writer/idempotent reader algorithms remain separate.
No source-only validation is a provider, writeback or full-cycle acceptance.

## Explicitly unavailable historical extensions

D5-linked OCR receipts, successor/registered effect-budget policy, authority-bearing
historical programme roots, additional physical versions/schemas, held migration,
private capture and native qualification/budget IPC cannot be run by ordinary
entrypoints. They refuse rather than dropping typed members, choosing an original
response over a foreign winner, resetting an intent or issuing a new paid call.
A v1 chosen winner keeps its complete binding, original hash/path, pinned owner
approval/authority, physical version, reconstructed request ID and genuine response
validation. Existing UNKNOWN outcomes remain UNKNOWN. No automatic retry exists.
The native prepareSimpleCompletionModelForAgent boundary and its positive OAuth,
profile/model/provider/endpoint checks remain before ordinary completion. The
optional qualification/preparation operator CLI and its budget driver are not
part of this public subset. This does not modify deployed/private implementations.

## Preserved admission and completion

Real mutable postrun and request-recovery READONLY fences run before provider
permission. Native pending/qualification contexts and supplied capture/budget
descriptors are refused, not replaced by constant-false query functions. Ordinary
NOT_STARTED versus DISPATCH_RESERVED journals, second immediate admission,
exclusive request writes, disk floor, pause, worker ownership/deadline/IO/reap and
unknown-stop behavior remain. Ownership takeover requires unavailable historical
retry authority and refuses rather than silently succeeding.

OCR proof retains lineage/source/started-receipt, exact namespace, artifact hashes,
reservation/response/page reconstruction, requested/returned model, cleanup and
PDF checks. Note proof retains real PASS/empty findings/full-source and payload
read flags, review/request/response hashes, parent/library/version/lineage,
scientific/final-lock identity, immutable safeHTML payload, one-wire journal,
fresh independent readback and explicit publication selection. Ordinary publication
retains local PDFs; no historical cleanup/fullcycle compatibility is claimed.

Native installation deployment metadata in credentials.py is intentional and
positively checked. No credential values, private research payloads or operator
acceptance reports belong in this source patch. Runtime configuration remains
private and must be supplied explicitly as described in native-profile-configuration.md.
