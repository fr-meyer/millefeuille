# Bounded summary stage selection

`millefeuille summarize-prepare --route-evidence ROUTE --structure-evidence STRUCTURE --output-dir NEW_DIR --summary-stage summarize_page --summary-stage summarize_full_paper --json` prepares all source evidence but requests only page and whole-paper summaries. Python callers pass `requested_stages=["summarize_page", "summarize_full_paper"]` to `prepare_summary_execution_packages`.

Omission preserves the existing all-stage package bytes and behavior. Explicit selections must be nonempty, unique known stage names in canonical page, section, full-paper order. Invalid values, duplicates, null in a saved package and unknown fields fail closed. Selection does not remove work units or skip source verification: the complete route, source text, structure, all canonical plans and all units are rederived before dispatch. Unselected section units remain in preparation but never become requests. Selected counts in the batch summary count only requested work. A selection with no units is not executable.

The optional requested_stages field is canonical preparation data. Its preparation digest is bound into every prompt/request; dispatch validates its exact selection and ordered unit coverage. The text-free execution manifest also exposes selection and its hash commits to it. Approval preview, trusted approval and the one-use reservation broker replan using this manifest and exact request count. A prior approval cannot authorize narrowing or widening; obtain a fresh exact manifest-bound receipt. Existing consumed reservations remain consumed. The trusted executor rechecks the same plan before every unit. No authorization, credential, provider, fallback or root configuration policy changes.

The nine-page real-paper no-call trial produces 10 requests (nine page, one full-paper), retains all 46 section units for verification and dispatches none of them. Planning is not provider execution or accepted-run evidence. Tests use explicitly synthetic receipts, fake model results and temporary mocked administrator ownership; those are not live approvals.
