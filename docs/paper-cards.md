# Standalone paper cards

Integration helper: `export_paper_card(run_dir, output_dir=None, *, memory_dir=None, project_comment=None)` in millefeuille.domain.paper_cards. Parent should call only after 06-completed.json exists. No model, network, OpenClaw, GCP or credential dependency. CLI adapter run_paper_card_cli(argv) is ready for parent dispatch under paper-card; main.py is deliberately unchanged. Direct module invocation: python -m millefeuille.cli.paper_cards --run-dir RUN [--output-dir DIR] [--memory-dir DIR] [--project-comment github.com/fr-meyer/openclaw-workspace]. JSON result, exit 0 on verified writes, 2 on refusal. Exceptions never print artifact content.

Default canonical card is beside run outputs, named LIBRARY-TYPE-LIBRARY-ID-ITEM.paper-card.md. A shared output-dir yields one current card per library/item. Explicit memory export is optional, with the same stable filename, canonical pointer and optional project comment on every content record. No unrelated file is touched. Managed marker includes schema, identity and body SHA256; manually edited or unmanaged cards refuse replacement. Updates replace only the managed current card, not historical run artifacts. Serialize writers to each destination; no hostile concurrent filesystem mutation guarantee. Input symlinks and path traversal refuse. Roots are caller-owned private directories.

Validation reads original source manifest, selection, completion, both stage hash records and their files, OCR evidence/fulltext, summary/classification/evidence/source map and taxonomy snapshot/lock. It verifies identity/version/source-hash joins and source-locator ranges. PDF bytes are deliberately not read: source SHA is manifest-attested, not independently reverified after retention. Original artifacts remain untouched. Run metadata is a local trust root, not a cryptographic authenticity claim.

Extractive description selects complete existing-summary sentences, targets 180 words and never exceeds 250, reserving a short limitation sentence where explicitly identifiable. Short/pathological input may yield fewer than 150 words rather than fabricate text. Generic scientific-description heading is intentional: no model is asked to infer unsupported problem/method/contribution labels. Important concepts remain in the source sentences and taxonomy label. Scientific correctness remains that of the prior generated summary, requiring parent review. Source text is escaped/quoted as data; URLs omitted, obvious credential-shaped strings refuse. This is not a universal secret detector. Raw request/provider payloads are hashed where stage-pinned but never embedded.

Portable retrieval paths are relative to canonical card directory; optional memory adapter uses local absolute references. Relocating the entire run tree preserves default relative references, not source-map absolute input bindings. Reruns require their matching current source manifest. Canonical write can succeed before an optional memory-export refusal; rerun is idempotent. No multi-file transaction or active indexing claim.
